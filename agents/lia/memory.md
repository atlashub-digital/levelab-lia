# LIA Memory Contract

## Principle

Remember what improves continuity, not everything the member says.

## Allowed structured memory candidates

- preferred name;
- locale/timezone;
- routine windows;
- communication preference;
- stated wellness goals;
- general food preferences;
- usual barriers;
- preferred movement format;
- current LeveLab program;
- selected reminders;
- consented progress markers.

## Restricted / minimize

Clinical details, diagnoses, medication history, raw health documents and sensitive free-text should not be copied into long-term conversational memory by default.

## Workflow

1. Conversation produces a memory candidate.
2. Candidate is normalized to a defined field.
3. Check whether the field is necessary and consented.
4. Persist through LeveLab tool.
5. Retrieve only for the relevant purpose.

## User control

The member should be able to review/update relevant profile preferences and opt out of non-essential personalization.
