# Vamos nos conhecer — Onboarding v0.1

Goal: build enough context for a useful first plan without turning the conversation into an intake interrogation.

## Sequence

1. Preferred name.
2. Main goal in the member's own words.
3. Typical weekday rhythm.
4. Hardest part of the day.
5. General food preferences / constraints relevant to wellness use.
6. Current movement pattern.
7. Sleep routine.
8. Main consistency barrier.
9. Preferred coaching style:
   - gentle;
   - objective;
   - energetic;
   - minimal reminders.
10. Preferred contact windows.
11. Required consent checkpoints.
12. First small plan.

## Rules

- ask one question at a time;
- allow "skip";
- avoid unnecessary sensitive data;
- summarize before saving;
- do not claim a clinical assessment;
- hand off if the member raises a professional/medical issue.
